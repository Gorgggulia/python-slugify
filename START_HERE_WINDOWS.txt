ЛР1: ЯК ЗАПУСТИТИ НА WINDOWS
=============================

ЩО ВІДКРИВАЄТЬСЯ ЗВИЧАЙНИМИ ПРОГРАМАМИ (нічого встановлювати не треба)
- Lab1_report.docx            -> Word
- coverage\htmlcov_baseline\index.html  -> двічі клікнути, відкриється в браузері
- *.txt, *.json, *.py, *.log  -> Блокнот або VS Code

ЩО ПОТРЕБУЄ ЗАПУСКУ (за бажанням, щоб відтворити результати самому)
Інструмент mutmut на самій Windows не працює (він використовує механізми Linux),
тому запускаємо через WSL, це вбудований у Windows Linux. Потрібен Windows 10 (22H2) або Windows 11.

КРОК 1. Встановити WSL (один раз)
1. Натисніть Пуск, введіть PowerShell, правою кнопкою -> "Запуск від імені адміністратора".
2. Виконайте:
       wsl --install -d Ubuntu
3. Перезавантажте комп'ютер. Після перезавантаження сам відкриється Ubuntu:
   придумайте ім'я користувача й пароль (пароль при введенні не показується, це нормально).
   Якщо Ubuntu не відкрилась, знайдіть її в меню Пуск.

КРОК 2. Розпакувати архів
Розпакуйте Lab1_artifacts.zip у просту папку без пробілів і кирилиці, наприклад C:\Lab1

КРОК 3. Запустити
У вікні Ubuntu виконайте по черзі:
       cd /mnt/c/Lab1
       sudo apt update && sudo apt install -y git python3 python3-venv python3-pip
       bash run_all.sh
Скрипт сам завантажить проєкт, встановить інструменти, порахує покриття, виконає
мутаційне тестування до і після додавання тестів. Це 4-8 хвилин. Рядки на екрані
з'являтимуться поступово, це нормально.

Очікуваний результат у останніх рядках:
       baseline: усього=1073 вбито=898 вижило=175 mutation score=83.69%
       after:    усього=1073 вбито=1056 вижило=17 mutation score=98.42%

КРОК 4. Подивитися результати
Усе з'явиться в папці C:\Lab1\results:
- SUMMARY.txt                  підсумок mutation score до і після
- coverage_baseline.txt        покриття рядків і гілок (оригінальні тести)
- coverage_after.txt           покриття після додавання тестів
- htmlcov_baseline\index.html  HTML-звіт покриття (скриншоти робіть звідси)
- mutmut_all_*.txt             список усіх мутантів (killed / survived)
Папку можна відкрити з Ubuntu командою:  explorer.exe .

ЧАСТІ ПРОБЛЕМИ
- "wsl не розпізнано": оновіть Windows або встановіть WSL з Microsoft Store.
- Помилка "\r: command not found": файл run_all.sh відкривали й зберігали в Блокноті.
  Виправте командою:   sed -i 's/\r$//' run_all.sh   і запустіть знову.
  Не редагуйте run_all.sh у Блокноті.
- Числа трохи відрізняються: це можливо, якщо вийшли нові версії залежностей. У звіт
  беріть ті, що вийшли у вас.
